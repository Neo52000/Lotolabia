# Guide de marque — LotoLab IA

## Identité

- **Nom officiel :** LotoLab IA (toujours en deux mots, « IA » en capitales)
- **Slogan principal :** Analysez. Comprenez. Jouez mieux.
- **Positionnement :** laboratoire statistique · technologie · pédagogie · transparence · fiabilité · jeu responsable

## Le symbole

Une **boule de tirage** contenant un **histogramme ascendant** : les données au cœur du jeu.
L'étincelle rose évoque l'analyse (« IA ») sans jamais promettre de prédiction.

Fichiers sources (SVG, `branding/svg/`) :

| Fichier | Usage |
|---|---|
| `mark.svg` | Symbole seul (réseaux sociaux, avatars) |
| `logo-principal.svg` / `logo-principal-dark.svg` | Logo empilé, fonds clairs / sombres |
| `logo-horizontal.svg` / `logo-horizontal-dark.svg` | En-têtes, documents |
| `logo-monochrome.svg` / `logo-monochrome-blanc.svg` | Impression 1 couleur, gravure, tampon |
| `app-icon.svg` | Icône d'application (base 1024) |
| `favicon.svg` | Favicon web |
| `splash.svg` | Écran de démarrage mobile (1080×1920) |

Les PNG sont générés par `python branding/generate_png.py` dans `branding/png/`
(toutes les tailles requises par l'App Store, le Play Store et le web).

## Palette

| Rôle | Couleur | Hex |
|---|---|---|
| Fond profond / texte principal | Bleu nuit | `#0D1B2A` |
| Couleur primaire | Bleu | `#00B4FF` |
| Secondaire | Violet | `#9D4EDD` |
| Accent (IA, alertes douces) | Rose | `#FF4D8D` |
| Avertissements | Jaune | `#FFC107` |
| Confirmations / positif | Vert | `#22C55E` |

Dégradé de marque : `#00B4FF → #9D4EDD` (45°).

## Typographie

- Titres : sans-serif géométrique bold (Inter / SF / Roboto selon plateforme), graisse 700-800.
- Texte : la police système de chaque plateforme (performance et accessibilité).
- Les SVG utilisent Arial/Helvetica en repli pour une portabilité maximale.

## Règles d'utilisation

1. **Zone de protection** : marge minimale autour du logo = hauteur de la boule ÷ 4.
2. **Taille minimale** : symbole 24 px ; logo horizontal 120 px de large.
3. Ne pas déformer, incliner, recolorer hors palette, ni ajouter d'ombre portée.
4. Sur photo ou fond chargé : utiliser la variante monochrome blanche.
5. **Interdictions absolues** :
   - ne jamais reprendre ou imiter les logos, trèfles, typographies ou codes visuels de la FDJ
     ou de tout opérateur de jeux ;
   - ne jamais associer le logo à des visuels promettant des gains (billets, liasses, jackpots) ;
   - ne jamais utiliser la marque avec les termes « gagnant », « numéros sûrs »,
     « prédiction fiable », « garantie de gain », « algorithme gagnant ».
6. Toute communication porte la mention : *« Outil indépendant d'analyse statistique — 18+ »*.

## Ton de voix

Pédagogue, précis, honnête. On explique, on ne promet pas.
On écrit « les statistiques décrivent le passé », jamais « nos numéros pour gagner ».
